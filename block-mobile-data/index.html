선불폰에서 모바일 인터넷 사용을 차단할 수 있나요?

모바일 데이터가 계속 소모된다면 휴대폰 설정에서 먼저 사용을 꺼 볼 수 있습니다.

휴대폰에서 끄거나 통신사 데이터 차단을 신청할 수 있습니다

앤텔레콤 선불폰에서 모바일 인터넷 사용을 제한하려면 휴대폰 자체의 모바일 데이터 설정을 끄거나 공식 고객센터에 무선데이터 차단 부가서비스를 문의할 수 있습니다.

갤럭시에서 모바일 데이터 끄기

화면 위쪽을 내려 빠른 설정을 열고 ‘모바일 데이터’를 끄세요. 설정 → 연결 → 데이터 사용에서도 변경할 수 있습니다. 이렇게 꺼 두면 휴대폰에서 직접 다시 켤 수 있습니다.

아이폰에서 모바일 데이터 끄기

설정 → 셀룰러에서 셀룰러 데이터를 끄면 됩니다. 특정 앱만 데이터를 쓰지 못하도록 설정하려면 같은 화면의 앱별 목록을 확인하세요.

와이파이에 연결돼 있다면 모바일 데이터 대신 와이파이로 인터넷을 이용할 수 있습니다.

통신사 차단이 필요한 경우

휴대폰 설정만으로 충분하지 않다면 앤텔레콤 공식 고객센터 114(앤텔레콤 번호·무료) 또는 1899-7700(유료)에 무선데이터 차단 서비스 신청 방법을 문의하세요.

모바일 데이터를 끄는 것은 일반 전화·문자 수신을 끄는 것과 다릅니다. 다만 인터넷이 필요한 메신저나 앱 통화는 제한될 수 있습니다.
