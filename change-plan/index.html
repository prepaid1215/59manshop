요금제 변경

앤텔레콤 요금제를 바꾸려면 어떻게 하나요?

데이터가 모자라거나 기본료를 줄이고 싶다면 현재 요금제를 먼저 확인하세요.

멤버십 앱의 셀프케어에서 요금제를 변경합니다

앤텔레콤 요금제는 이용 중인 망의 멤버십 앱 → 셀프케어 → 요금제 변경에서 변경 가능한 상품을 선택합니다. K망과 L망은 변경 가능 시점과 잔액 처리 방식이 다를 수 있습니다. 지금 사용하는 요금제와 다음 상품의 데이터·적용일·충전 잔액을 함께 살펴보고 변경을 진행하세요.

KT망과 LG망은 언제부터 바꿀 수 있나요?

공개된 선불요금제 FAQ에서 소개하는 일반적인 기준은 K망은 가입 다음 달 1일부터, L망은 가입 30일 뒤부터 월 1회입니다. 실제 적용 가능 여부는 가입한 상품의 종류와 멤버십 앱에서 표시되는 변경 가능일에 따릅니다.

구분K망 선불L망 선불
변경 가능 시점일반 안내 기준 가입 다음 달 1일부터일반 안내 기준 가입 30일 뒤부터
변경 횟수멤버십 앱에서 표시되는 제한 적용일반 안내 기준 월 1회
요금 처리잔액·차액 및 적용 시점 확인남은 이용기간·잔액 처리 확인

신규가입 전용 구성이나 약정형 상품은 일반 기준과 달리 변경 가능한 상품이 제한될 수 있습니다. 날짜만 보고 선택하기보다 앱에 실제로 표시된 상품명과 적용일을 기준으로 처리합니다.

K396·459를 이용 중이면 무엇을 비교하나요?

K396은 월 39,600원에 기본 데이터 10.3GB, K459는 월 45,900원에 20.3GB인 신규가입 구성으로 사용됩니다. 두 상품의 월 요금 차이는 6,300원, 기본 데이터 차이는 10GB입니다. 기본 제공량을 소진하면 최대 3Mbps로 인터넷을 이용하는 조건도 함께 비교하세요.

중요한 점은 가입 당시의 신규가입 혜택이 요금제 변경 후 자동으로 유지되는 것은 아니라는 것입니다. 변경 화면의 새 상품명과 실제 제공량을 먼저 살펴보세요. 단순히 가격 숫자만 같은 상품을 선택하면 이전의 혜택과 구성이 달라질 수 있습니다.

충전 잔액이 남았다면 어떻게 하나요?

K망과 L망은 선불 기본료가 차감되는 방식부터 다릅니다. K망은 하루치 기본료가 나뉘어 차감되고, L망은 월 기본료를 먼저 차감하는 방식입니다. 따라서 변경 후 이용 기간과 잔액을 같은 방법으로 계산하지 않습니다.

  1. 기존 요금제 이름과 잔여 사용량을 메모합니다.
  2. 변경할 요금제의 기본료·데이터·영상·부가통화 조건을 비교합니다.
  3. 앱에 표시되는 적용 날짜와 추가 충전 여부를 살펴봅니다.
  4. 변경 완료 후 멤버십 앱에서 적용된 요금제와 남은 이용기간을 다시 확인합니다.

월중 변경 시 기본료·제공량이 조정될 수 있습니다. 실제 차감 내역은 월중 요금제 변경 안내와 앱의 적용 화면을 함께 기준으로 삼습니다.

잘못 선택했다면 다시 신규가입해야 하나요?

아닙니다. 이미 이용 중인 번호의 요금제를 조정하는 문제라면 새로운 신규가입 신청서를 만들지 않습니다. 멤버십 앱의 변경 가능 상품을 살펴보거나 공식 고객센터에서 현재 상태를 확인하면 됩니다.

가입한 망 자체를 KT에서 LG로 바꾸고 싶은 경우에는 단순한 요금제 변경과 다릅니다. 같은 망 안에서 상품을 바꾸는 일인지, 다른 망의 서비스를 이용하려는 일인지 먼저 구분합니다.

요금제 변경 추가 질문

K396 가입 후 데이터가 부족하면 459로 바꿀 수 있나요?

멤버십 앱에서 변경 가능한 상품을 선택합니다. 변경 가능 시점과 적용 데이터 구성은 앱에 표시되는 상품이 기준입니다.

요금제를 바꾸면 기존 충전액은 사라지나요?

망과 상품에 따라 차감·잔액 처리 방식이 다릅니다. 변경 화면에 표시된 적용 기간과 추가 충전 조건을 기준으로 진행합니다.

KT망에서 LG망으로 바꾸는 것도 같은 메뉴인가요?

아닙니다. 망을 바꾸는 문제는 같은 통신망 안에서 요금제를 변경하는 절차와 구분합니다.
