교통카드 오류

선불폰을 개통했는데 휴대폰 교통카드가 안 됩니다. 왜 그럴까요?

통화는 정상인데 버스나 지하철 교통카드가 안 된다면 유심부터 다시 볼 필요가 있습니다.

교통카드는 NFC 기능과 교통카드 앱의 등록 상태가 중요합니다

선불폰 개통과 교통카드 등록은 별개입니다. 사용하는 교통카드 서비스에 따라 NFC 유심·휴대폰 NFC 설정·앱 등록이 필요합니다. 일반 유심만으로는 지원되지 않는 서비스도 있습니다.

먼저 유심에 NFC 표시가 있는지 확인하세요

교통카드 서비스 중에는 NFC 기능이 있는 유심을 요구하는 방식이 있습니다. KT 바로유심이라도 상품 종류를 확인해야 하고, LG 원칩 역시 해당 기능 지원 여부를 봐야 합니다.

유심 교체가 필요하다면 현재 사용 중인 교통카드 서비스가 유심 기반인지, 휴대폰 자체 NFC 기반인지 먼저 확인하세요. 불필요하게 유심부터 구매하지 않아도 됩니다.

갤럭시라면 휴대폰 설정도 확인

휴대폰 설정에서 NFC 및 비접촉 결제 기능이 켜져 있는지 확인합니다. 교통카드 앱을 사용하는 경우에는 그 앱에 카드가 정상 등록됐는지도 살펴보세요.

개통한 뒤 휴대폰을 재부팅하지 않았다면 전원을 다시 켜고, 앱에서 번호 등록이나 본인확인 단계를 요구하는지도 확인하세요.

이렇게 나눠 보면 쉽습니다

  • NFC 메뉴가 아예 없다면: 휴대폰 기기 지원 여부부터 확인
  • NFC는 켜지는데 카드 등록이 안 된다면: 교통카드 앱·유심 지원 조건 확인
  • 등록은 됐는데 단말기에 인식되지 않는다면: 기본 결제 앱과 NFC 설정 확인
