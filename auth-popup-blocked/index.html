셀프개통 중 본인인증 팝업이 안 열리면 어떻게 하나요?

인증 버튼을 눌렀는데 아무 화면도 뜨지 않을 때 확인할 설정입니다.

먼저 브라우저의 팝업 차단 여부를 확인하세요

인증 버튼을 눌러도 새 창이 열리지 않는다면 팝업 차단이나 브라우저 설정 때문일 수 있습니다. 현재 신청을 무작정 다시 시작하지 말고, 인증창 차단 표시가 있는지 먼저 살펴보세요.

갤럭시·안드로이드 Chrome이라면

  1. 신청 화면에서 팝업 차단 표시가 나오면 항상 표시를 눌러 해당 창을 열어 봅니다.
  2. 계속 차단되면 Chrome의 설정 → 사이트 설정 → 팝업 및 리디렉션에서 설정을 확인합니다.
  3. 인증을 마친 다음에는 원래 개통 탭으로 돌아와 신청 상태를 확인합니다.

아이폰 Safari라면

설정 → 앱 → Safari → 팝업 차단에서 차단 설정을 확인합니다. 정상적인 인증창이 필요한 경우 잠시 설정을 조정하고, 인증을 끝내면 다시 원래 상태로 되돌립니다. 모르는 광고창이나 별도 앱 설치를 요구하는 창은 열지 마세요.

팝업이 아니라 카카오·토스·PASS 앱으로 전환된 상황이라면, 인증 승인 후 원래 열었던 개통 브라우저로 복귀합니다. 인증 화면에서 이미 제출이 완료됐다면 같은 신청을 반복하지 말고 현재 상태부터 확인하세요.
