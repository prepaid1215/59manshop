전화·문자는 되는데 모바일 인터넷만 안 되면?

유심을 다시 살 필요가 있는지 판단하기 전에 데이터 설정부터 살펴봅니다.

모바일 데이터가 켜져 있고 올바른 SIM이 선택됐는지 확인하세요

통화와 문자가 되는데 인터넷만 안 된다면 모바일 데이터 설정, 듀얼심의 데이터용 SIM 선택, 남은 데이터 이용 상태를 먼저 확인합니다. 와이파이로 인터넷이 되는 것과 모바일 데이터가 정상인지는 별개입니다.

먼저 3가지를 확인하세요

  1. 와이파이를 잠시 끄고 웹페이지를 열어 모바일 데이터 연결을 시험합니다.
  2. 갤럭시는 설정 → 연결 → 데이터 사용에서 모바일 데이터를, 아이폰은 설정 → 셀룰러에서 셀룰러 데이터를 켭니다.
  3. 듀얼심이라면 데이터용 SIM이 개통한 KT·LG 선불유심으로 선택돼 있는지 확인합니다.

여전히 연결되지 않는다면

휴대폰을 재부팅하고 멤버십 앱에서 요금제·잔여 데이터·충전 상태를 확인합니다. 갤럭시는 일부 기기에서 설정 → 연결 → 모바일 네트워크 → 액세스 포인트 이름의 기본 설정 복원으로 해결되는 경우가 있습니다. 임의의 APN 값을 인터넷에서 복사해 입력하지 마세요.

특정 앱만 접속되지 않으면 해당 앱의 모바일 데이터 사용 허용·로그인 상태부터 확인합니다. 통신망 전체 문제와 앱 하나의 문제를 구분하면 불필요한 유심 교체를 피할 수 있습니다.
