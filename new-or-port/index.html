신규가입과 번호이동은 무엇이 다른가요?

가입 화면에서 ‘신규가입’과 ‘번호이동’ 중 무엇을 눌러야 할까요?

기존 번호를 유지할지가 선택 기준입니다

신규가입은 본인 명의의 010 번호를 발급받아 시작하는 방법입니다. 번호이동은 현재 다른 통신사에서 이용 중인 번호를 그대로 옮기는 방법입니다. 둘은 준비할 조건과 접수 시간이 다릅니다.

지금 사용 중인 번호가 꼭 필요하다면

현재 번호를 계속 사용해야 한다면 번호이동 조건을 확인하세요. 이전 통신사 번호가 정상 상태여야 하고 번호이동 동의 절차가 필요할 수 있습니다. 기존 번호를 먼저 해지하면 이동이 어려워집니다.

통신요금 미납으로 번호가 정지됐다면

정지된 번호는 번호이동이 제한될 수 있습니다. 이럴 때 번호이동을 여러 번 시도하기보다 선불 신규가입이 가능한지 확인하는 편이 빠릅니다. 신규가입은 기존 번호를 옮기는 방식이 아니라 별도의 번호를 발급받는 방식입니다.

온라인에서 무엇을 선택하나요?
