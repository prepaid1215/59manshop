월 17,000원 상품은 통화와 문자가 무제한인가요?

아닙니다. 앤텔레콤 L망 2.5GB 요금제는 월 17,000원에 데이터 2.5GB, 음성통화 100분, 문자 50건을 제공합니다. 저렴한 가격에 끌려 가입하기보다 통화·문자 제공량이 정해져 있다는 점을 먼저 확인해야 합니다.

예전 사용 요금제의 기본 제공량이 아니라 스마트폰의 최근 실제 이용량을 기준으로 살펴보세요. 영상과 지도 사용량이 많으면 데이터가 부족할 수 있고, 영업이나 상담 전화를 오래 받는 용도라면 100분이라는 수치를 특히 확인해야 합니다.

제공량 초과 시 처리 조건이나 추가 요금은 신청 화면에서 실제 상품 설명을 읽어 확인해야 합니다. 데이터를 다 쓴 뒤 3Mbps가 제공되는 L망 464 상품과는 성격이 다릅니다.

본인인증용·세컨폰이라면 무엇을 생각해야 할까요?

기존 휴대폰 번호를 유지하면서 업무용 회선을 하나 더 만드는 경우, 필요한 것은 먼저 번호를 받을 수 있는 본인 명의 회선입니다. 인증문자 확인과 간헐적인 연락이 중심이라면 2.5GB의 기본 제공량이 맞을 수 있습니다.

다만 특정 서비스의 본인인증 성공 여부는 해당 서비스가 지원하는 통신사·회선 조건에 따라 다릅니다. 모든 앱에서 인증된다고 단정할 수는 없습니다. 통화량이 일정하지 않거나 문자 발송이 잦은 업무라면 100분·50건을 넘길 가능성을 고려해 다른 요금제를 비교하세요.

  • 자주 Wi-Fi에 연결하는 소량 데이터 사용
  • 짧은 업무 연락·비상용 번호 추가
  • 여러 서비스를 인증할 예정이라면 해당 서비스의 가입 조건부터 확인

원칩을 구매하면 처음에 얼마가 필요한가요?

월 이용요금은 17,000원입니다. 원칩을 새로 구매한다면 유심 구입비 8,800원이 별도이므로 요금 17,000원과 원칩 가격 8,800원을 나누어 생각하면 됩니다. 매장별 재고와 실구매 가격은 방문 전 확인해야 합니다.

실물 유심은 L망 모두의 원칩 구매 안내에서 확인할 수 있습니다. 이미 원칩이 있다면 동일한 상품을 다시 구입할 필요 없이 카드 정보를 준비하세요.
