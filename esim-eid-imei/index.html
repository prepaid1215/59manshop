eSIM 신청에 필요한 EID와 IMEI는 어디서 확인하나요?

EID는 eSIM 식별정보이고 IMEI는 휴대폰 기기 식별정보입니다.

아이폰은 설정 → 일반 → 정보에서 EID와 IMEI를 확인합니다

아이폰에서 설정 → 일반 → 정보로 들어가 아래로 내리면 EID와 IMEI를 확인할 수 있습니다. EID는 eSIM 관련 식별정보, IMEI는 휴대폰 기기 식별번호입니다. eSIM 신청 화면에서 요구하는 항목을 확인하고 서로 바꿔 입력하지 마세요.

기기에서 확인하는 순서

  1. 아이폰: 설정 → 일반 → 정보 → EID·IMEI 항목을 찾습니다.
  2. 갤럭시: 설정 → 휴대전화 정보에서 IMEI를 확인하고, eSIM 지원 기종은 SIM 관리자와 기기정보의 EID 표시 여부를 확인합니다. 기종·소프트웨어에 따라 표시 메뉴가 다를 수 있습니다.
  3. 표시된 숫자를 신청 화면에 직접 입력합니다. IMEI와 EID를 다른 사람에게 전부 보여주는 캡처는 피합니다.

EID가 보이면 eSIM 개통이 완료된 건가요?

아닙니다. EID가 표시된다는 사실은 개통 완료 또는 통신사 지원을 보장하지 않습니다. 사용할 통신망, 휴대폰 모델, eSIM 발급과 설치 조건을 별도로 확인해야 합니다.

앤텔레콤 선불 신규가입에서 eSIM은 L망 지원 조건을 기준으로 확인하고, 실제 신청 화면의 안내에 따라 진행합니다.
