홈 · 유심 안내

바로유심은 어떤 유심인가요?

KT 바로유심은 K망에서 사용하는 NFC 유심입니다. 개통할 때는 카드에 있는 19자리 번호를 입력합니다.

바로유심은 이렇게 개통해요

먼저 제품이 K망용인지 확인하세요. 카드에 있는 19자리 유심정보를 신청 화면에 정확히 입력하면 됩니다. 판매처를 찾는 것보다 입력값과 신규가입·번호이동 선택을 확인하는 것이 먼저입니다.

개통 전에 시간과 입력 정보를 확인해요

신규가입은 매일 08:00~21:50에 개통할 수 있고, 주말과 공휴일도 포함합니다. 번호이동은 월~토 10:00~19:50에 개통할 수 있으며, 일요일과 공휴일에는 진행하지 않습니다. 본인인증은 안면인증을 먼저 하고, 이어서 간편인증을 진행합니다. 신청 화면에서 통신망(K망 또는 L망)과 신규가입·번호이동을 고른 뒤, K망 유심카드의 19자리 번호를 입력하세요.

19자리 번호는 이렇게 입력해요

유심 번호는 기억에 의존하지 말고 실제 카드에서 확인해 입력하세요. 입력한 뒤에는 K망과 신규가입·번호이동 선택이 맞는지 확인하세요.

새 번호냐 기존 번호냐에 따라 달라요

새 번호가 목적이면 신규가입을, 기존 번호를 유지하려면 번호이동 조건을 먼저 확인하세요. 유심은 준비됐지만 번호이동이 가능한지 확실하지 않다면 시간 또는 번호이동 안내를 먼저 보세요.

19자리를 확인했다면 신청해요

K망 선택과 19자리 입력 준비가 끝났다면 신규가입·번호이동 중 맞는 방법으로 개통을 시작하세요.
