선불폰 신청을 끝내면 바로 통화할 수 있나요?

‘신청 완료’ 화면까지 봤는데 통화가 안 된다면 충전 단계를 확인하세요.

개통 완료 후 충전까지 마쳐야 통화할 수 있습니다

웹 셀프개통은 가입 신청 → 개통 완료 확인 → 요금 충전 → 유심 장착·재부팅까지 끝내야 사용을 시작할 수 있습니다. 신청서 제출만으로 통화가 시작되는 것은 아닙니다.

신청 완료와 개통 완료는 다릅니다

신청 완료는 유심정보와 요금제 등 가입 내용을 제출한 상태입니다. 이후 개통 처리가 완료됐는지 화면에서 확인하세요. 웹 셀프개통에는 담당자가 별도로 승인해 주는 단계가 없습니다.

개통이 끝났다면 홈페이지의 요금 충전 메뉴에서 사용할 요금에 맞게 충전합니다. 충전이 반영돼야 사용할 수 있습니다.

휴대폰은 언제 다시 켜나요?

첫 충전까지 마친 뒤 개통한 망에 맞는 유심을 장착하고 전원을 껐다 켭니다. 이후 통화 한 번, 문자 한 건, 모바일 데이터 접속을 차례로 확인하세요.

통화만 되고 인터넷이 안 된다면 데이터 설정을, ‘SIM 없음’이 보인다면 유심 장착 상태를 먼저 점검합니다.

태블릿 회원번호를 넣었다면 순서가 다릅니다

멤버십 앱을 이용했다면 고객이 신청서를 제출한 다음 담당자 승인을 거칩니다. 승인 후 충전 안내를 받고 이용요금을 충전해 사용을 시작합니다.

웹 셀프개통과 앱 신청은 서로 다른 흐름이니, 어떤 방식으로 접수했는지 먼저 확인하면 됩니다.
