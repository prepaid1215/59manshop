앤텔레콤 번호로 본인인증할 때 통신사를 무엇으로 선택하나요?

앤텔레콤 이용자는 인증 화면에서 일반 KT·LG와 알뜰폰을 구분해야 합니다.

K망은 ‘알뜰폰 KT’, L망은 ‘알뜰폰 LG’로 선택하세요

앤텔레콤으로 개통한 번호를 다른 사이트에서 본인인증할 때는 알뜰폰 통신사를 선택합니다. K망 이용자는 ‘알뜰폰 KT’, L망 이용자는 ‘알뜰폰 LG유플러스’를 선택하면 됩니다.

KT를 사용하면 그냥 KT를 누르면 되나요?

앤텔레콤은 KT망을 사용하더라도 KT 본사 가입자가 아닌 알뜰폰 가입자입니다. 본인인증 화면에 KT와 알뜰폰 KT가 나뉘어 있다면 알뜰폰 쪽을 선택하세요.

알뜰폰 항목이 안 보이면?

본인인증 서비스를 제공하는 사이트마다 통신사 목록이 다릅니다. 알뜰폰 메뉴가 보이지 않는다면 목록을 다시 펼쳐보고, 찾을 수 없다면 해당 사이트의 고객센터에 문의하세요.

인증문자가 오지 않는다면

통신사를 올바르게 골랐는지 확인하고 휴대폰의 문자 수신 상태를 살펴보세요. 수신정지된 번호라면 문자 인증을 받을 수 없을 수 있습니다. 인증 서비스별 지원 방법이 다르므로 오류 문구를 확인하는 것이 좋습니다.
