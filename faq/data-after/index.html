앤텔레콤 396 요금제는 10.3GB를 다 써도 인터넷을 계속 사용할 수 있나요?

핵심 답변

네. K망 LTE 선불 396 요금제는 기본 데이터 10.3GB를 모두 사용한 이후에도 최대 3Mbps 속도로 데이터를 계속 이용할 수 있습니다. 다만 실제 체감 속도는 사용 환경과 서비스에 따라 달라집니다.

기본 데이터 10.3GB와 3Mbps의 의미

10.3GB는 제공 속도로 사용할 수 있는 기본 데이터 용량입니다. 제공량을 소진하면 최대 3Mbps 속도제어가 적용됩니다. 즉, 데이터를 소진했다고 인터넷이 바로 끊어지는 형태의 요금제가 아닙니다.

어떤 용도로 이용할 수 있을까요?

메신저, 지도, 검색과 일반적인 웹페이지 확인에는 이용할 만하지만 고화질 영상, 대용량 파일 전송, 동시에 여러 기기에서 사용하는 상황에서는 답답할 수 있습니다. 최대 3Mbps는 실제 속도를 보장한다는 뜻은 아닙니다.
