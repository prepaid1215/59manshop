KT 바로유심 19자리와 LG 원칩 모델코드·일련번호는 어떻게 입력하나요?

핵심 답변

앤텔레콤 K망에서는 KT 바로유심 카드의 유심번호를 19자리 형식으로 입력하며, 안내에 따라 문자 F는 제외합니다. L망은 유심 모델코드 5자리와 일련번호 8자리를 구분해 입력합니다.

KT 바로유심 입력

K망 신청 화면에서 유심카드에 적힌 번호를 확인합니다. 카드의 19자리 숫자 형식을 따르고, 번호 끝에 F가 표시된 경우 F를 제외해 입력합니다. 유심 종류에 따라 표기 위치가 다를 수 있으므로 카드 인쇄 정보를 확인하세요.

LG 모두의 원칩 입력

L망 신청 화면은 유심 모델코드와 일련번호를 각각 받는 방식입니다. 안내 기준으로 모델코드 5자리, 일련번호 8자리를 해당 칸에 나누어 입력합니다. 입력 칸의 예시가 다르면 실제 개통 화면을 우선 확인합니다.

오입력을 줄이는 방법

카드 표면의 번호를 직접 대조하고, O와 0 또는 I와 1처럼 혼동하기 쉬운 글자를 재확인합니다. 제품 포장에 적힌 다른 번호나 영수증 번호를 입력하지 않도록 주의하세요. 입력 오류가 나면 먼저 망 선택과 유심 종류가 맞는지 확인합니다.
