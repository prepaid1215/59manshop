앤텔레콤 홈페이지 셀프개통과 멤버십 앱 개통은 무엇이 다른가요?

핵심 답변

홈페이지 셀프개통은 고객이 본인확인부터 신청과 요금 충전까지 직접 진행하는 방식입니다. 멤버십 앱 접수는 신청 후 담당자의 확인·승인 및 충전 안내 과정이 포함됩니다.

홈페이지에서 직접 진행하는 경우

59만모바일 홈페이지의 KT·LG 개통 버튼으로 웹 신청 화면에 들어갑니다. 고객이 가입 유형, 본인인증, 유심정보, 요금제, 번호 선택을 진행하고 개통 완료 후 요금을 직접 충전합니다. 담당자 승인 절차는 없습니다. 본사 해피콜 안내가 있는 경우 해당 전화도 확인합니다.

앤텔레콤 멤버십 앱을 이용하는 경우

앱에서는 안내된 태블릿 소유자 회원번호를 입력하는 단계가 있습니다. 접수 후에는 담당자의 신청 확인·승인, 해피콜, 충전 안내 및 처리 과정이 이어집니다. 따라서 웹에서 혼자 충전까지 끝내는 방식과 진행 주체가 다릅니다.

어떤 방식을 선택할까요?

웹 신청 화면에서 지원되는 간편인증을 준비할 수 있고 직접 진행하려면 홈페이지 셀프개통이 적합합니다. 앱에서 별도 회원번호를 입력해 접수하는 경우에는 담당자에게 후속 절차를 안내받습니다. 두 방식 모두 본인 명의 신청과 정확한 정보 입력이 필요합니다.
