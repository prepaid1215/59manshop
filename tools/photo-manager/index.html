각 글에서 사진을 넣을 위치를 확인하고, 직접 촬영하거나 사용 권한이 있는 이미지를 준비할 수 있습니다. 이미지가 없는 위치는 일반 방문자에게 나타나지 않습니다.

2. GitHub에 업로드

GitHub Pages는 업로드 서버가 없는 정적 사이트입니다. 여기서 파일을 선택하는 것만으로 사이트에 저장되지는 않으며, 아래 GitHub 업로드까지 완료해야 합니다.

  1. 위에서 WebP 파일 저장을 선택합니다.
  2. GitHub 이미지 폴더에서 Add file → Upload files를 클릭하고 저장된 파일을 올립니다.
  3. Commit changes를 누르면 GitHub Pages 배포 후 해당 글에 사진이 자동 표시됩니다.

파일명은 바꾸지 마세요. 신분증·연락처·생년월일·IMEI/EID·QR코드 등 개인정보나 인증정보가 포함된 사진은 올리지 마세요.

GitHub 이미지 폴더 열기

GitHub에서 저장소 수정 권한이 있는 계정으로 로그인해야 업로드할 수 있습니다. 별도 액세스 토큰을 입력할 필요는 없습니다.
