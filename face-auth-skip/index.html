안면인증 건너뛰기를 눌러도 괜찮나요?

‘건너뛰기’가 보여도 모든 본인확인이 끝나는 것은 아닙니다.

건너뛰기를 눌러도 간편인증은 진행합니다

개통 화면에 안면인증 건너뛰기 버튼이 표시됐다면 해당 단계를 넘어갈 수 있습니다. 하지만 이후에 나오는 카카오·토스·PASS 간편인증까지 생략되는 것은 아닙니다.

버튼을 눌렀다면 다음 화면에서 할 일

안면인증은 신분증과 얼굴을 확인하는 단계입니다. 보통 PASS 앱이나 모바일신분증을 이용한 확인을 먼저 진행합니다. 이 과정에서 건너뛰기를 선택했다면 다음 단계의 간편인증을 마쳐야 합니다.

카카오, 토스, PASS 중 본인이 이용하는 수단을 선택하고, 해당 앱에서 인증을 승인한 다음 다시 개통 화면으로 돌아오세요. 앱을 설치했다는 사실만으로는 인증이 완료되지 않습니다.

건너뛰기가 안 보인다면?

화면에 없는 버튼을 찾으려고 뒤로 가기를 반복할 필요는 없습니다. 표시된 안면인증 방법을 선택해 진행하면 됩니다. 본인 명의로 인증할 수 있는 앱과 신분증을 준비해 두면 중간에 멈출 일을 줄일 수 있습니다.

인증이 끝난 뒤 진행 순서

유심정보 입력 → 요금제 선택 → 전화번호 선택 → 신청 완료 순서로 이어집니다. 웹 셀프개통이라면 개통이 완료된 뒤 요금 충전도 직접 진행합니다. 신청 완료와 충전 완료를 같은 단계로 생각하지 않으면 됩니다.
