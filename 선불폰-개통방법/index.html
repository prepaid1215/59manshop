준비, 인증, 입력, 확인 순서로 진행합니다

선불폰 개통방법은 크게 네 부분입니다. 먼저 준비물을 갖추고, 안면인증과 간편인증으로 본인확인을 한 뒤, 유심 정보와 요금제를 입력해 신청합니다. 마지막으로 개통 완료를 확인하고 유심을 장착합니다. 앤텔레콤 신청 화면의 단계 구성은 앤텔레콤 셀프개통 방법에서 볼 수 있고, 신청 가능 시간은 선불폰 개통 안내에 있습니다.

유심을 아직 사지 않았다면 통신망을 먼저 정한 뒤 편의점 선불유심 안내에서 구매처를 확인하세요.

본인인증은 안면인증 다음 간편인증입니다

본인확인은 안면인증을 먼저 하고, 이어서 간편인증으로 마무리합니다. 인증 받을 전화번호와 간편인증 수단이 모두 가입자 본인 명의인지 미리 확인하세요. 다른 사람 명의의 인증 수단으로는 신청을 진행할 수 없습니다.

유심 정보는 망마다 입력 형식이 다릅니다

K망은 유심카드에 적힌 19자리 번호를 입력합니다. L망은 모델코드 5자리와 일련번호 8자리를 입력합니다. 입력란이 두 개로 나뉘어 있다면 두 번호를 붙여 넣지 말고 각 칸에 따로 입력하세요.

입력 전에 유심 포장에 적힌 번호와 화면의 입력란을 함께 보고, 구입한 유심이 선택한 통신망용인지도 확인하세요.

요금제와 번호를 고르고 신청을 마칩니다

유심 정보를 입력한 다음 사용량에 맞는 요금제를 고르고 새 번호를 선택한 뒤 최종 신청합니다. 요금제별 데이터와 가격은 선불 요금제 비교에서 미리 확인해 두면 신청 화면에서 망설이지 않아도 됩니다.

개통 완료 후 확인할 것

신청 화면을 닫았다고 개통이 완료된 것은 아닙니다. 개통 완료 안내를 확인한 다음 새 유심을 휴대폰에 장착하고 전화 걸기, 전화 받기, 데이터 연결을 차례로 점검하세요. 연결되지 않으면 휴대폰을 다시 시작하고 유심이 제대로 꽂혔는지 확인합니다.
