eSIM을 추가할 때 와이파이가 꼭 필요한가요?

eSIM 설치에는 활성화 정보를 내려받을 인터넷 연결이 필요합니다.

eSIM 설치 전에 와이파이 등 인터넷 연결을 준비하세요

eSIM은 휴대폰에 디지털 통신 정보를 내려받아 설치하므로 설치 과정에서 인터넷 연결이 필요합니다. 기존 모바일 데이터가 끊긴 휴대폰이라면 안정적인 와이파이를 준비한 다음 진행하세요. 앤텔레콤 선불 신규가입의 eSIM은 L망 지원 조건을 먼저 확인합니다.

아이폰에서는 어디에서 설치하나요?

지원 기종에서 설정 → 셀룰러 → eSIM 추가로 이동합니다. 통신사에서 제공한 활성화 방법이 QR코드인지 다른 방법인지는 실제 발급 안내를 따릅니다. 모든 eSIM이 QR코드 하나로 동일하게 설치되는 것은 아닙니다.

설치가 멈춘다면

  1. 와이파이가 정상 연결돼 있는지 확인합니다.
  2. 휴대폰에 eSIM이 이미 추가돼 있는지 설정 → 셀룰러에서 살펴봅니다.
  3. 설치 실패 문구와 발급 상태를 확인합니다. 같은 eSIM을 임의로 반복 설치하거나 이미 설치한 eSIM을 삭제하지 마세요.

eSIM을 추가하는 과정과 신규가입·요금 충전은 별도 절차입니다. 설치가 끝나도 통화가 안 된다면 개통 및 충전 완료 상태를 확인합니다.
