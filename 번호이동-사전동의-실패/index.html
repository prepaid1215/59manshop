이 화면에서 먼저 할 일

번호이동에서 사전동의가 진행되지 않는다면 신청하려는 새 통신망보다, <strong>현재 번호를 관리하는 기존 통신사</strong>를 정확히 선택했는지 먼저 확인하세요. 특히 알뜰폰은 판매 브랜드와 실제 통신사업자 이름이 다를 수 있습니다.

브랜드명과 사업자명이 다를 수 있습니다

휴대폰 요금 청구서·고객센터·가입 정보를 보고 현재 회선을 운영하는 사업자를 확인하세요. 단순히 KT망이나 LG망을 사용한다는 사실만으로 신청 화면의 기존 통신사 선택값이 맞는 것은 아닙니다.

기존 통신사를 잘못 선택했다면 먼저 정확한 사업자를 확인한 뒤 번호이동 단계로 돌아갑니다. 동일 신청을 여러 번 접수하지 마세요.

사전동의가 막혔을 때 확인할 순서

  1. 기존 회선이 현재 정상 이용 상태인지, 미납·정지·해지 제한이 없는지 확인합니다.
  2. 사업자 선택과 기존 번호, 가입자 정보가 실제 청구 정보와 일치하는지 확인합니다.
  3. 화면에서 요구하는 문자·ARS 또는 안내된 사전동의 절차를 진행했는지 확인합니다.
  4. 진행 시간이나 사전동의 유효시간이 지나지 않았는지 확인하고, 같은 오류가 계속되면 기존 사업자 고객센터에 문의합니다.

확인할 점: 미납·정지 상태의 번호는 번호이동이 제한될 수 있습니다. 기존 번호를 유지할 수 없다면 신규가입을 별도로 검토하세요.

가입 기간이 짧아 생기는 제한과는 구별해야 합니다

기존 통신사를 정확히 선택했어도 가입일로부터 90일이 지나지 않은 회선이라면 별도 제한이 발생할 수 있습니다. 이 경우는 통신사 선택 오류와 해결 경로가 다르므로 90일 미경과 번호이동 안내를 참고하세요.

해결되지 않으면 어디서 확인할까요?

오류가 발생한 단계와 화면에 나타난 정확한 문구를 적어 두세요. 이미 신청서를 제출했다면 새 접수를 반복하기 전에 현재 신청 상태를 확인합니다. 본인확인 정보 전체를 댓글이나 공개 게시판에 게시하지 마세요.
