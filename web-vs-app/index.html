웹 셀프개통과 멤버십 앱, 어떤 차이가 있나요?

두 방법 모두 온라인 신청이지만, 신청을 마친 다음 순서가 다릅니다.

웹은 직접 충전하고, 앱은 담당자 승인을 거칩니다

웹 셀프개통은 본인이 인증·신청·충전까지 직접 합니다. 멤버십 앱개통은 신청서를 제출한 뒤 담당자 승인과 충전 안내를 받습니다. 태블릿 소유자 회원번호 입력 화면이 나왔다면 앱 방식입니다.

웹 셀프개통 순서

59만모바일 개통 페이지에서 KT·LG망과 신규가입을 선택합니다. 안면인증 → 카카오·토스·PASS 간편인증 → 유심정보·요금제·번호 입력 → 개통 완료 → 요금 충전 순서입니다. 담당자 승인이나 해피콜은 없습니다.

멤버십 앱으로 신청했다면

태블릿 소유자 회원번호 2893496을 입력하고 표시된 담당자 이름을 대조합니다. 신청서 제출 후 담당자 승인과 충전 안내를 받고, 충전이 끝나면 유심을 장착해 휴대폰을 다시 켭니다.

어느 방식으로 신청했든 신청서 제출만으로 통화가 시작되지는 않습니다. 개통 완료와 충전 완료를 구분하는 방법을 참고하세요.
