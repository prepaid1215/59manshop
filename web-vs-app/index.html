웹 셀프개통과 멤버십 앱, 어떤 차이가 있나요?

두 방법 모두 온라인 신청이지만, 신청을 마친 다음 순서가 다릅니다.

홈페이지와 앱의 가장 큰 차이는 승인 절차입니다

홈페이지 셀프개통은 고객이 본인인증부터 충전까지 직접 완료합니다. 반면 멤버십 앱은 신청서를 제출한 뒤 담당자 승인과 충전 안내를 거치는 방법입니다.

홈페이지에서 혼자 진행하려는 경우

59만모바일 홈페이지에서 KT 또는 LG 개통하기를 누르고 신규가입을 선택합니다. 안면인증 다음 간편인증을 마친 뒤 유심번호, 요금제, 사용할 번호를 선택하세요.

개통 처리가 완료되면 요금을 직접 충전하고 유심을 장착하면 됩니다. 담당자 승인을 기다리는 절차가 없습니다. 처음부터 충전까지 한 흐름으로 진행하고 싶은 분에게 맞는 방식입니다.

멤버십 앱으로 신청했다면

앱 신청에는 태블릿 소유자 회원번호 입력 단계가 있습니다. 번호를 넣으면 연결되는 담당자 이름을 확인할 수 있습니다. 신청서 제출 후에는 담당자 승인 단계가 있으므로 웹 신청처럼 곧바로 충전 화면으로 끝나는 방식이 아닙니다.

승인 후 받은 안내에 따라 요금을 충전하고, 유심을 장착해 휴대폰을 다시 켜면 됩니다.

어느 쪽으로 신청했는지 헷갈릴 때

신청 도중 태블릿 소유자 회원번호를 입력했다면 멤버십 앱 방식입니다. 홈페이지에서 신규가입을 선택하고 직접 개통·충전 화면을 거쳤다면 웹 셀프개통입니다.

두 방식의 가장 큰 차이는 신청 속도가 아니라 담당자 승인이 필요한지입니다. 같은 단계라고 생각하고 기다리거나 중복 신청하지 마세요.
