웹 셀프개통과 멤버십 앱, 어떤 차이가 있나요?

두 방법 모두 온라인 신청이지만, 신청을 마친 다음 순서가 다릅니다.

웹은 본인이 개통·충전까지, 앱은 담당자 승인 후 충전합니다

웹 셀프개통은 고객이 안면인증·간편인증부터 유심정보 입력, 신규가입, 요금 충전까지 직접 진행합니다. 앤텔레콤 멤버십 앱은 태블릿 소유자 회원번호를 입력해 신청서를 제출하고 담당자 승인과 충전 안내를 거칩니다. 두 방식 모두 본인 명의 가입이며, 진행 순서가 다릅니다.

표에서 가장 중요한 구분은 회원번호 입력 여부와 담당자 승인을 기다리는지입니다. 어느 쪽이 더 빠르다고 일률적으로 단정할 필요 없이, 지금 사용한 신청 화면을 기준으로 다음 단계를 선택하면 됩니다.

웹 셀프개통은 어떤 순서로 끝나나요?

  1. 59만모바일 개통 페이지에서 KT 또는 LG를 선택한 다음 신규가입을 누릅니다.
  2. PASS 앱 또는 모바일신분증 등을 이용한 안면인증 단계 뒤 카카오·토스·PASS 간편인증을 진행합니다.
  3. 준비한 유심의 번호를 입력하고 요금제·이용할 번호를 선택합니다.
  4. 개통 완료 화면을 보고 요금 충전까지 직접 마칩니다.
  5. 유심을 장착하고 휴대폰을 재부팅한 다음 통화·문자·데이터를 사용합니다.

이 방식에는 태블릿 소유자 회원번호 입력, 담당자 승인, 담당자 해피콜이 없습니다. 신청을 마쳤는데 이용되지 않는다면 개통 완료와 충전 완료의 차이부터 살펴보세요.

멤버십 앱에서는 누구의 회원번호를 입력하나요?

앱 신청에는 태블릿 소유자 회원번호를 입력하는 화면이 있습니다. 59만모바일 태블릿 소유자 회원번호는 2893496입니다. 번호를 입력한 뒤 표시되는 담당자 이름이 안내받은 담당자와 맞는지 살펴보세요. 번호를 잘못 입력하면 다른 담당자로 접수될 수 있습니다.

신청서를 제출한 다음에는 담당자 승인과 충전 안내가 이어집니다. 승인이 완료되지 않은 앱 신청을 웹 셀프개통으로 착각해 반복 신청하지 마세요. 담당자 안내에 따라 요금을 충전한 후 유심을 장착해 휴대폰을 다시 켭니다.

이미 신청했다면 다음 행동은 무엇인가요?

  • 웹에서 개통 완료를 보았음: 요금을 충전하고 유심을 장착합니다.
  • 앱에서 회원번호를 넣고 제출했음: 연결된 담당자의 승인·충전 안내를 따릅니다.
  • 어느 화면이었는지 모르겠음: 회원번호 입력 여부와 현재 상태 문구를 보고 신청 경로를 구분합니다.
  • 전화가 아직 안 됨: 충전 여부, 개통한 망, 유심 장착 상태를 차례로 확인합니다.

웹과 앱 개통 추가 질문

웹으로 신청해도 담당자의 승인을 기다리나요?

아닙니다. 웹 셀프개통은 고객이 직접 개통과 충전을 마치는 흐름입니다.

앱 신청에서도 회원번호 없이 넘어갈 수 있나요?

태블릿 소유자 회원번호 입력 단계가 나타나면 안내받은 번호를 입력하고 담당자 이름을 확인합니다.

신청서를 제출하면 바로 통화할 수 있나요?

아닙니다. 개통 완료와 첫 요금 충전이 끝난 뒤 유심을 장착하고 휴대폰을 다시 켭니다.
