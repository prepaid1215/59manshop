# SERP 키워드 분리 3개 페이지 — 사전 검증 메모
기준: 2026-10-15 · 상태: 개발 브랜치 초안, 미배포

## 목표
네이버 SERP에서 '선불폰 개통', '선불폰 개통방법', '선불폰 셀프개통'의 노출 결과 URL이 다른 관측을 바탕으로 각 검색의도에 독립적으로 답하는 고유 페이지를 시험한다.

## 페이지별 역할
- /선불폰-개통/: 신규가입 신청 판단, 유심·망 선택, 즉시 개통 CTA. 거래형
- /선불폰-개통방법/: 안면인증, 간편인증, 유심번호, 번호채번, 완료 확인. 방법형
- /선불폰-셀프개통/: 혼자 신청 가능한 조건과 화면별 막힘 대처, eSIM. 문제 해결형

## 안전 조건
- main 미수정, 페이지는 seo-lab-v01에만 존재
- 기존 19개 index 대상 및 현재 canonical, CTA 목적지 그대로 유지
- 실험 브랜치 내 세 페이지에 self-canonical/index, sitemap.xml에 3개 추가한 배포 후보 상태
- 블로그 원문 복제, 경쟁사 자산·코드 복제, 키워드 치환 도어웨이 페이지 금지
- 실서버 배포 및 IndexNow 전송 전 사용자 승인·검수 필요
- 기존 앤텔레콤 개통 안내와 내용이 상당히 겹치는 것으로 판단되면 개별 URL을 보류
- 각 페이지의 검색 의도별 고유성, 링크 유효성, 모바일 레이아웃, 실제 요금제·가입 조건 검수
- 배포 전 반드시 현재 index 19개 URL의 기준 노출 상태를 기록하고, 홈/허브→3개 새 URL로의 자연스러운 내부 유입 경로를 설계한 뒤 검증
- 전환 성과는 preplan.site 이동 클릭뿐 아니라 실제 신청·개통 완료를 별도 집계해야 함

## 1차 관찰 항목
- URL HTTP 200, meta robots, canonical, site map, 전환 링크
- 네이버 URL 검사 상태 (수집, 색인 구분)
- 키워드별 PC·모바일 검색 블록/등장 URL/첫 관측 시각
- 검색 방문→개통 클릭→실제 개통 완료 (연결 가능한 집계만)
