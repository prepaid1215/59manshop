# SEO Lab 구현 작업 규칙

이 문서는 59man.shop 신규 SEO 실험의 승인되지 않은 대량 배포를 방지한다.
실험은 `seo-lab-v01` 분기에서 작업하고, 검토 전 main 배포를 하지 않는다.

- 기본 브랜드 `59만선불폰`, 개통서비스 `59만모바일` 분리 유지
- 6개 비교군(5개 경쟁사 구조 모델 + 기존 V4.1) 설계, 1차 각 4개 문서
- 경쟁사의 구조는 참고하지만 HTML 소스, 문장, 브랜드, 이미지, 허위 혜택을 복제하지 않는다
- 각 문서는 독립적으로 고객에게 도움이 되는 고유 원본이어야 한다; 얇은 키워드 치환/문 입구 페이지 금지
- 396 요금제는 K망만 표기. K망 459 월 45,900원, L망 5G 464 월 46,400원 등 최신 확정 상품정보 사용
- 59man.shop 현재 index URL / preplan.site 지역 URL 의 검색의도 중복 검증 필수
- 배포전 검증에서 하나라도 실패하면 미공개; 4개씩 6그룹 중 준비된 문서부터 순차 공개
- 웹사이트에서는 사용자를 위한 정상 안내만 노출하고 내부 실험 문서/메타데이터는 사용자-facing 텍스트로 복제하지 않는다
- Yeti 첫 크롤링 시각은 GitHub Pages 로그로 측정되지 않는다. 노출 관측과 색인 확정은 분리 표기
- IndexNow YES/NO 그룹은 공식 Naver 엔드포인트를 사용하되, 색인보장 문구는 금지
- `experiments/seo-lab/PLAN.md` 및 `experiments/seo-lab/manifest.csv`를 먼저 확인한다
