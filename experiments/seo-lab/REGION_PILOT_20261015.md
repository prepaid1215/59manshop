## 변경사항
- 신규 URL `/신림동-선불폰-개통/` (self-canonical, index/follow).
- 운영 형태를 비대면 신규가입으로 명확하게 표기하고 방문매장·재고·즉시개통을 주장하지 않는다.
- 신청 후 승인 → 첫 충전 → 유심 장착 또는 eSIM 설치 → 재부팅 → 통화/데이터 점검 및 해피콜 수신을 안내한다. 세부 단계는 공통 개통방법 페이지로 연결한다.
- 판매점·유심 색상(세븐일레븐, 빨간색 고고비)은 운영 측에서 제공한 제품 안내를 기반으로 유지했으며, 점포별 판매·재고는 별도 확인 대상이다.
- 홈과 /guide에 새 URL 내부링크 각 1개, 실험용 사이트맵에 새 URL 추가 (22 → 23).
- CTA 추적 코드 `from=59man_%EC%8B%A0%EB%A6%BC%EB%8F%99-%EC%84%A0%EB%B6%88%ED%8F%B0-%EA%B0%9C%ED%86%B5` (디코딩 값: `59man_신림동-선불폰-개통`). 실제 GTM·GA4·신청 완료로 귀속되는지 검증하기 전에는 단순 식별 파라미터이다.
