## 오프라인 재분류
최초 Actions 아티팩트에서는 `/region/gil-dong`, `/region/hajung-dong`, `/region/ihwa-dong`, `/region/oryu-dong`을 URL 깊이만 보고 허브로 잘못 분류했다. 네 문서 모두 H1이 각 지역의 선불폰 셀프 개통 안내였으므로 `regional_candidate`로 수정한다.

`reclassify_competitor_results.py --in <원본.json> --out <수정.json>`을 실행하면 기존 HTTP 검사 결과 120개를 재사용해 분류만 수정한다. 외부 URL에 재요청하지 않는다. 최초 원본 메타데이터는 [Actions 38848075481](https://github.com/prepaid1215/59manshop/actions/runs/38848075481)의 `competitor-frozen-http-type-results` 아티팩트에 7일 보관한다. 분류기는 새 작업 시 기존 URL 120개를 자동 재요청하지 않도록 **workflow_dispatch 전용**으로 바꾸었다.

## 해석 범위
- HTTP 200은 네이버 검색로봇 방문·색인·검색 노출을 증명하지 않는다.
- 지역 페이지 118개는 **표본 내 URL 유형 후보**이고, 실제 사이트의 전체 지역 URL 수를 의미하지 않는다.
- 경쟁사 페이지 본문 유사도는 아직 측정하지 않았으며, 새로 수집할 경우 원본 HTML은 외부 공개 저장소에 올리지 않는다.
- 유사도 분석에서 ntelact의 선불폰 9개와 알뜰폰 11개는 섞지 않는다.
- 59man.shop 운영 `main`과 1,000페이지 미배포 상태는 유지.
