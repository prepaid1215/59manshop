## 측정 단계별로 확인된 것과 확인되지 않은 것
| 단계 | 상태 | 근거 |
|---|---|---|
| 1. 59man.shop 페이지 방문 | 측정 불가 | 59man.shop에 분석 스크립트 없음, GitHub Pages는 접속 로그를 제공하지 않음 |
| 2. 개통 버튼 클릭 → preplan.site 도착 | **확인 필요** | 2026-10-15 preplan.site 첫 화면 HTML에서 GTM 컨테이너(GTM-NB2K5MFQ)와 Site Kit 확인. GA4가 연결되어 있다면 도착 URL에 from 값이 남을 수 있으나, 실제 GA4 보고서에서 확인하지 못함 |
| 3. preplan.site → 실제 신청 화면 이동 | 미확인 | 첫 화면의 'KT 개통하기 / LG 개통하기'는 스크립트 버튼이라 이동 대상과 from 값 전달 여부를 정적 검사로 알 수 없음 |
| 4. 신청 접수 | 미확인 | 신청 기록에 from 값이 저장되는지 알 수 없음 |
| 5. 개통 완료 | 미확인 | 개통 완료 기록과 from 값을 연결하는 수단이 확인되지 않음 |

**결론:** 지금 확보된 것은 "어느 페이지에서 출발한 링크인지 구분할 수 있는 표시"뿐이다. 클릭 수, 신청 수, 개통 완료 수는 아래 검증이 끝나기 전에는 측정된다고 가정하지 않는다. 클릭과 개통 완료는 별도 지표로 기록한다.

## 배포 전후 검증 체크리스트 (사람이 직접 수행)

- [ ] preplan.site 첫 화면에서 실제 신청 화면으로 넘어갈 때 from 값이 유지되는지 확인 (주소창 또는 GTM 미리보기)
- [ ] 신청 기록(관리자 화면 등)에 유입 출처를 남길 수 있는지 확인. 불가능하면 '개통 완료 추적 불가'로 기록
