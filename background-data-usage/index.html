인터넷을 안 썼는데 데이터가 줄어드는 이유는 무엇인가요?

휴대폰을 사용하지 않았는데 데이터가 줄어들었다면 앱별 사용량을 먼저 확인해 보세요.

앱이 화면 밖에서도 데이터를 사용하기 때문입니다

휴대폰 화면을 꺼 두어도 사진 백업·앱 업데이트·메신저 동기화·동영상 자동 재생 때문에 모바일 데이터가 쓰일 수 있습니다. 통신요금 문제가 생겼다고 판단하기 전에 실제 사용량이 어디에서 발생했는지 확인하는 것이 먼저입니다.

가장 먼저 볼 메뉴

갤럭시: 설정 → 연결 → 데이터 사용 → 모바일 데이터 사용량

아이폰: 설정 → 셀룰러 → 앱별 데이터 사용량

이 화면에서 데이터 사용량이 큰 앱을 확인하세요. 오래 켜 두지 않았는데도 사용량이 많다면 자동 백업이나 자동 재생 기능을 살펴보면 됩니다.

생각보다 데이터를 많이 쓰는 기능

  • 사진과 동영상을 자동으로 클라우드에 올리는 기능
  • 앱스토어의 앱 자동 업데이트
  • 유튜브·SNS에서 다음 영상이 자동 재생되는 설정
  • 노트북과 연결한 핫스팟 사용

문자 몇 건이나 가벼운 알림보다 사진·영상과 파일 업데이트가 사용량에 더 큰 영향을 줄 수 있습니다.

다음 달부터 데이터 사용을 줄이고 싶다면

앱 업데이트는 와이파이에서만 실행하고, 사용하지 않는 앱의 백그라운드 데이터 사용을 제한하세요. 사진 백업도 와이파이에 연결했을 때만 진행하도록 설정할 수 있습니다.

이렇게 조정해도 매달 기본 데이터를 모두 사용한다면 데이터 제공량이 넉넉한 요금제로 바꾸는 편이 더 편할 수 있습니다.
